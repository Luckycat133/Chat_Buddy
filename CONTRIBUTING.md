# Contributing to Chat Buddy

Thank you for considering contributing to Chat Buddy.

[English](#english) | [中文](#中文)

---

## English

### Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Chat_Buddy.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Commit: `git commit -m 'feat: add your feature'`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

### Commit Convention

We use [Conventional Commits](https://www.conventionalcommits.org/):

- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation changes
- `style`: Code formatting
- `refactor`: Code refactoring
- `test`: Test updates
- `chore`: Maintenance

### Code Style

- Run `npm run lint` before committing
- Use functional components and hooks
- Add translations for new UI text in both `en.js` and `zh.js`

### Development Setup

See [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## 中文

### 开始

1. Fork 本仓库
2. 克隆：`git clone https://github.com/你的用户名/Chat_Buddy.git`
3. 创建分支：`git checkout -b feature/你的功能`
4. 进行修改
5. 提交：`git commit -m 'feat: 添加xx功能'`
6. 推送：`git push origin feature/你的功能`
7. 创建 Pull Request

### 提交规范

遵循 [约定式提交](https://www.conventionalcommits.org/zh-hans/)：

- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更新
- `refactor`: 代码重构

### 代码规范

- 提交前运行 `npm run lint`
- 使用函数组件和 Hooks
- 新增 UI 文本需同时添加中英文翻译

### 开发环境

详见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。
