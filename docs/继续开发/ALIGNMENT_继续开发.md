## 开发顺序分析

根据 ROADMAP 定义的开发阶段:

```
Phase 1 (Foundation): T01 → T02 → T03  ← T03 Phase 4 仍待完成
Phase 2 (Core Role-Play): T04 → T05 → T06 → T07 → T08
Phase 3 (Atmosphere & Social): T09 → T10 → T11
Phase 4 (Intelligence): T12 → T13 → T14 → T15
```

### 建议优先级

根据依赖关系和完成度，推荐按以下顺序推进：

1. **T03 Phase 4 — 页面迁移 & 打磨** (Foundation 层收尾)
   - 将现有内联按钮样式迁移到组件类
   - 聊天界面重新设计 (简洁消息列表)
   - 设置页面重新设计 (分组区块, 现代切换控件)
   - Dashboard 精修 (Bento Grid 优化)
   - _理由_: Foundation 层应当优先完成，为后续所有功能提供一致的 UI基础

2. **T05 — AI 行为拟人化补全**
   - 在线/离线/忙碌状态模拟
   - 时间问候 (早安/晚安)
   - AI "编辑中" 状态
   - 消息撤回模拟
   - _理由_: Phase 2 的核心，直接影响用户体验的"真实感"

3. **T06 — 好感度 & 心情系统**
   - 好感度计分系统 (0-100)
   - 5种心情状态
   - _理由_: 依赖 T05 的状态系统，是角色扮演的灵魂功能

## 项目特性规范

### 源码目录结构

```
src/
├── core/chat/          # ChatEngine.js + AIPipeline.js (领域逻辑)
├── services/           # api/ (aiClient, APIClient), storage/, perplexityService
├── features/           # background/ (4), chat/ (25), moments/ (8)
├── context/            # 8 个全局 Context
├── data/               # 9 个数据文件 (personas, taskAgents, locales...)
├── pages/              # 11 个页面组件
├── components/         # 10 个共享组件
├── providers/          # Context 组合层
├── hooks/              # 自定义 hooks
└── utils/              # 7 个工具模块
```

### 设计原则

- **iOS 26 Liquid Glass** + **ChatGPT Fluid Minimalism** 设计语言
- 社交功能"被动可发现" — 不强制弹窗、不红点轰炸
- AI 角色拥有独立记忆，信息交换是自发行为
- 任何 OpenAI 格式 API 即插即用

### 技术约束

- 纯前端项目 (无后端)，数据存储在 localStorage
- API Key 放在 `.env` 文件中
- 使用 TailwindCSS 4 + CSS Variables 做主题系统
- React Router v7 做路由
