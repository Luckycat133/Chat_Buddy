## 🔴 高优先级问题清单 (P0-P1)

### P0 - 必须修复（上线阻塞）

#### BUG-001: 聊天列表筛选逻辑缺陷
- **严重程度**: 🔴 高  
- **问题类型**: 功能缺陷  
- **位置**: [ChatList.jsx L224-L229](../src/features/chat/ChatList.jsx#L224-L229)
- **描述**: 任务专家类型的聊天会话被硬编码过滤掉，用户无法在聊天列表中看到这些会话  
- **重现步骤**:
  1. 创建一个任务型聊天（Task Agent）
  2. 返回聊天列表页面
  3. 观察该聊天是否显示
- **预期行为**: 所有类型的聊天都应在列表中显示  
- **实际行为**: 任务型聊天被过滤隐藏  
- **影响范围**: 核心业务功能受阻，用户无法访问特定类型的聊天  
- **修复建议**: 移除或修改硬编码的过滤条件，增加用户可控的筛选选项  
- **风险评估**: 
  - 发生概率: 100%（必然触发）
  - 影响范围: 使用Task Agent功能的用户
  - 缓解措施: 必须在上线前修复

### P1 - 强烈建议修复（影响用户体验）

#### BUG-002: AIPipeline工具解析器变量未定义
- **严重程度**: 🟠 高  
- **问题类型**: 功能缺陷  
- **位置**: [AIPipeline.js L84](../src/core/chat/AIPipeline.js#L84)
- **描述**: catch块中引用了未定义的变量payload，导致解析失败时抛出ReferenceError  
- **重现步骤**:
  1. 发送消息给AI
  2. AI返回格式错误的工具调用标记
  3. 观察控制台错误
- **预期行为**: 优雅地处理解析错误，返回null  
- **实际行为**: 抛出ReferenceError导致异常  
- **修复建议**: 将`payload`改为正确的变量名（如`raw`）  
- **截图证据**: 单元测试失败日志

#### BUG-003: 排行榜功能不完整
- **严重程度**: 🟠 高  
- **问题类型**: 功能缺陷  
- **位置**: [LeaderboardPage.jsx L60-L63](../src/pages/LeaderboardPage.jsx#L60-L63)
- **描述**: 仅亲密度排行实现了完整排序逻辑，其他维度只显示当前用户数据  
- **重现步骤**:
  1. 进入排行榜页面
  2. 切换到"活跃度"、"成就数"等标签
  3. 观察排名数据
- **预期行为**: 所有维度都应显示完整的用户排名列表  
- **实际行为**: 非亲密度维度只有当前用户数据  
- **影响范围**: 社交竞争功能失效，降低用户参与度  
- **修复建议**: 实现其他维度的完整排序和展示逻辑

### 安全建议

1. **API密钥存储**: 当前将API密钥存储在sessionStorage中，建议：
   - 使用后端代理转发API请求
   - 或实现短期token机制
   
2. **localStorage容量**: 大量使用localStorage可能导致5MB限制问题，建议：
   - 清理过期数据
   - 迁移至IndexedDB存储大数据

3. **定期安全审计**: 建议每月运行`npm audit`和`npm audit fix`
